    Thesis

    AI-Based Deepfake Detection using 3D Geometry & Audio-Visual Synchronization

    • Detector built on texture-independent signals (3D facial geometry + audio), so it doesn't rely on pixel artifacts that diffusion/NeRF fakes no longer leave.
    • 468 3D landmarks per frame (MediaPipe Face Mesh); nose-relative depth features for jaw, lips, eyes, cheeks; feature set grown 8 → 21 → 48 with velocity, acceleration and inter-region features.
    • Classical baseline: Random Forest reached 86% accuracy, 0.92 F1 on FaceForensics++ (vs Logistic Regression, XGBoost).
    • Temporal models: BiLSTM, BiGRU, TCN, Transformer Encoder; BiLSTM/BiGRU best (F1 ~85–86%, AUC ~89–90%).
    • Cross-dataset test on Celeb-DF and FakeAVCeleb: 17–38 point accuracy drop, showing in-dataset accuracy overstates robustness.
    • Audio pipeline on FakeAVCeleb (750 real / 750 fake): 63 librosa features → 1,701 per-video statistics → 25–100 selected; BiLSTM hit 98.67% accuracy, 97.39% precision, 100% recall.
    • Finding: fake speech never reaches the low spectral centroid, low zero-crossing rate and narrow bandwidth of natural pauses. Future work: audio-visual fusion linking jaw/mouth depth motion to acoustic energy.
